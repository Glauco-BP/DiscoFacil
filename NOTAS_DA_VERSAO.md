## DiscoFácil 12.22

Baixe o **`DiscoFacil_12.22_Windows_64bits.zip`** abaixo (em Assets; os "Source code" são só o código), descompacte e abra o `DiscoFacil.exe`. O tutorial em PDF vem junto. Só para Windows 64 bits.

> **Aviso "Editor desconhecido" / "O Windows protegeu o computador":** é normal na primeira vez que se abre uma versão nova (o programa não tem assinatura digital paga). Clique em **Mais informações → Executar assim mesmo**. Ou, antes de descompactar: botão direito no zip → **Propriedades** → marque **Desbloquear** → OK.

**Novidade**
- **Modo leve** (Configurações, ligado de fábrica): o programa força menos o computador. O ffmpeg roda com prioridade baixa, e o ✂ Editar mede uma coisa de cada vez. Num notebook, o processador em 100% por muito tempo esquentava a ponto de o Windows cair. Os cortes são os mesmos; o programa fica só um pouco mais lento. Para o máximo de velocidade (computador de mesa bem ventilado), desmarque.
