## DiscoFácil 12.20

Baixe o **`DiscoFacil_12.20_Windows_64bits.zip`** abaixo (em Assets; os "Source code" são só o código), descompacte e abra o `DiscoFacil.exe`. O tutorial em PDF vem junto. Só para Windows 64 bits.

> **Aviso "Editor desconhecido" / "O Windows protegeu o computador":** é normal na primeira vez que se abre uma versão nova (o programa não tem assinatura digital paga). Clique em **Mais informações → Executar assim mesmo**. Ou, antes de descompactar: botão direito no zip → **Propriedades** → marque **Desbloquear** → OK.

**Correção**
- **🔍 Busca de playlists:** dizia "confira se a YouTube Data API Key está configurada" mesmo com a chave configurada (uma peça não ia junto no programa desde a 12.18). Agora funciona, e se a API falhar a mensagem diz o motivo (chave recusada, cota do dia esgotada, sem internet...).
- **Vídeos de um canal:** voltam a ser listados pela YouTube Data API (mais rápida e completa) quando há chave.
